# ISPD 2005 Placement Benchmarks

This directory contains Bookshelf-format placement benchmarks used to
validate the Python reference implementation and the C++ reimplementation.

Expected files for each benchmark include:

- `.aux`
- `.nodes`
- `.nets`
- `.pl`
- `.scl`
- `.wts`

Source: ISPD 2005 Placement Contest.

Before publicly redistributing these files, verify the applicable
benchmark redistribution terms.
